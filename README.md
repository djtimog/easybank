# 🌐 Easybank Landing Page

A modern, responsive landing page built as part of a [Frontend Mentor](https://www.frontendmentor.io/) challenge.  
This project focuses on creating a clean, accessible, and pixel-perfect user interface using **Next.js** and **Tailwind CSS**.

---

## 🚀 Overview

The **Easybank Landing Page** project is a frontend-only implementation designed to improve my UI/UX development skills and strengthen my experience with **Tailwind CSS**.  
It was one of my first Tailwind projects, where I practiced building reusable components, maintaining responsive layouts, and following design specifications closely.

---

## 🧠 Key Features

- ✨ Pixel-perfect design following the challenge specifications  
- 📱 Fully responsive layout for desktop, tablet, and mobile  
- 🎨 Built entirely with Tailwind CSS utility classes  
- ⚡ Optimized for performance and accessibility  
- 🧩 Reusable and component-based structure with Next.js

---

## 🧰 Technologies Used

| Technology | Purpose |
|-------------|----------|
| **Next.js** | Framework for building the React-based UI |
| **Tailwind CSS** | Styling and responsive design |
| **TypeScript** | Type safety and cleaner component logic (optional if added later) |
| **Vercel** | Deployment platform |
